Employee Attrition Prediction

Project Overview

This project analyzes employee data and uses machine learning to predict employee attrition (whether an employee is likely to leave the company).

Objectives

- Analyze employee attrition patterns.
- Explore factors such as overtime, job satisfaction, and department.
- Train a classification model using Logistic Regression.
- Evaluate model performance using accuracy, precision, recall, F1-score, and a confusion matrix.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

Dataset

This project uses a synthetic dataset of 500 employee records with 21 columns. It was created for educational and internship practice purposes and does not represent real company employees.

Workflow

1. Load and inspect the dataset.
2. Check missing values and duplicates.
3. Perform exploratory data analysis (EDA).
4. Visualize attrition patterns.
5. Encode categorical features.
6. Split the dataset into training and testing sets.
7. Train a Logistic Regression model.
8. Evaluate the model and generate predictions.

Files

- "employee_attrition_prediction_dataset.csv" — dataset
- "Employee_Attrition_Prediction.ipynb" — notebook
- "employee_attrition_model.pkl" — trained model

Disclaimer

The dataset and model are for educational purposes only. Predictions are estimates, not guarantees, and should not be used alone to make employment decisions.
